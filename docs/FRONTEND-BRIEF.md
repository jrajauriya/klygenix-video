# Klygenix Play — frontend brief

Klygenix Play is an AI-first video platform (brand "Klygenix Play", internal name "video"): long videos and vertical reels, Bilibili-style danmaku (timestamped comments flying over the video), AI chapters/summary/transcript/search-inside/Ask-this-video with timestamp citations, a creator studio that turns one long video into captioned vertical clips, plans (Viewer Premium, Creator Pro), and trust & safety. Product plan: `../Klygenix_Docs/Klygenix_Video/klygenix-video-master-plan.html` (read §01, §06, §12–§14, §17).

## Running things
- API: `http://localhost:9300` (FastAPI, already running; restart with `cd backend && ./venv/bin/uvicorn app.main:app --port 9300`). Contract: `docs/openapi.json` (also live at `/openapi.json`, docs at `/docs`).
- Apps: web `:5300` (`npm run dev:web`), studio `:5301`, admin `:5302`, mobile Metro `:8082`. Vite proxies `/api` to :9300, but the shared axios client (`packages/auth/src/api.ts`) calls `VITE_API_URL || http://localhost:9300` directly; CORS allows all app ports.
- Accounts: global admin `admin@klygenix.com` / `admin123` (admin console). Creators/viewers: sign up via `POST /api/auth/signup` `{name,email,password,birth_date:"YYYY-MM-DD",country:"IN",language:"en",handle?,channel_name?}` (handle → also opens a channel). Under-18 in India / under-13 elsewhere is refused (403).
- Demo content: published videos/reels exist after `python3 db-scripts/seed-demo.py` (may already be seeded). Fixture videos: `tests/fixtures/media/*.mp4`.
- Verify: `cd apps/<app> && npx tsc --noEmit -p tsconfig.app.json` (the bare `tsc` checks nothing) and `npx vite build`. For a visual check use headless Chrome: `"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --disable-gpu --user-data-dir=/tmp/kv-chrome --window-size=1280,900 --virtual-time-budget=5000 --screenshot=/tmp/x.png http://localhost:5310/...` against `npx vite preview` (min window width headless = 500px).

## Conventions (binding)
- React 19, Vite 6, TypeScript strict, React Router 7 (`createBrowserRouter`), TanStack Query 5, Zustand (auth only), Tailwind 4. Every workspace package used by an app must be `@source`d in that app's `src/index.css`, or its classes are never generated.
- Shared packages: `@klygenixvideo/ui` (Card, Button, Input, Select, Modal, Drawer, Tabs, Badge, StatCard, PageHeader, DataTable, Pager, FileDropzone, ConfirmDialogProvider/useConfirm, Toaster, AppShell/Header/Sidebar, theme), `@klygenixvideo/auth` (`api` axios instance with JWT interceptor, `useAuthStore`, `useLogin`, `useSession`, LoginPage, SignupPage…), `@klygenixvideo/client` (`useList`, `useListPage` reading `X-Total-Count`, `useOne`, `useSave`, `useRemove`, `useAction`, `formatMoney`/`toMinor`, `ProtectedRoute`, `configureApp`), `@klygenixvideo/player` (to be built by the web agent). Read their `src/index.ts` before writing anything new.
- No `window.confirm`/`alert` — `useConfirm()`. Row click opens a drawer. Money is minor units; format with `formatMoney`.
- **No code comments or docstrings** (owner's rule). Small, readable components.
- Brand accent fuchsia `#A21CAF` (hover `#C026D3`, light `#FDF4FF`). Viewer web is dark-first (background `#0b0b12`), studio/admin light with dark theme support as already in `packages/ui`.
- Studio routes carry both `featureKey` and `permissionKey` (keys: `video.dashboard`, `video.uploads`, `video.clips`, `video.channels`, `video.comments`, `video.analytics`, `video.billing`, `video.users`, `video.settings`); the server enforces the same keys. Admin keys: `admin.dashboard`, `admin.tenants`, `admin.moderation`, `admin.takedowns`, `admin.ai_usage`, `admin.plans`, `admin.logs`, `admin.email`, `admin.team`, `admin.settings`.
- Embeds (YouTube/Bilibili): **never draw anything over the third-party player**; danmaku shows in a rail beside it (`playback.overlay_allowed === false`). Credit the source and link to it. Never paywall an embed.
- AI-generated videos show an "AI-generated" label (`ai_generated`).
- Never commit. Do not edit `backend/`, `infra/` or other agents' folders. If the API lacks something you need, append the exact need to `docs/API-GAPS.md` and build the UI against the closest existing endpoint.
- Do not run `npm install` at the root unless your brief says you may.

## Key API shapes (see openapi.json for all)
- `GET /api/video/feed/home|reels|following` → video cards `{id(public_id), title, kind:"long"|"reel", source, duration_ms, duration, thumbnail, views, likes, published_at, ai_generated, embed_platform, channel:{handle,name,avatar,followers,verified}}`; reels also carry `playback`.
- `GET /api/video/videos/{id}` → card + `description, tags, playback:{type:"hls",url}|{type:"youtube"|"bilibili",url,source_url,credit,overlay_allowed:false}, captions:{available:[lang],translatable:[lang]}, insight:{summary,key_points,chapters:[{start_ms,title}],tags}, liked, following, resume_ms, is_owner, ai_status`.
- Captions: `GET /api/video/videos/{id}/captions/{lang}.vtt`; transcript: `GET .../transcript` → `{segments:[{start_ms,end_ms,label,text}]}`.
- Danmaku: `GET .../danmaku?from_ms&to_ms` (fetch in 60 s buckets ahead of playhead), `POST .../danmaku {t_ms,text<=60,mode:"scroll"|"top"|"bottom",color:"#RRGGBB"}`; realtime `ws://localhost:9300/api/video/ws/videos/{id}` sends `{type:"hello",watchers}`, `{type:"danmaku",item}`, `{type:"danmaku_removed",id}`; send `"ping"` every 25 s.
- Comments: `GET/POST .../comments` (`parent_id` for replies), `DELETE /api/video/comments/{id}`. Like: `POST/DELETE .../like`. Follow: `POST/DELETE /api/video/channels/{handle}/follow`. Progress: `POST .../progress {position_ms, watched_ms, started, completed}` (send `started:true` once, then every ~15 s).
- Ask: `POST .../ask {question}` → `{answer, citations:[{start_ms,label,text}], status:"answered"|"declined", quota:{used,limit}}`; 402 when the daily quota is used. `GET .../ask` history.
- Search: `GET /api/video/search?q=` → `{results:[card + moment:{start_ms,label,snippet}]}` — open the watch page at `?t=<start_ms>`.
- Me/plans/billing: `GET/PATCH /api/video/me`, `GET /api/video/plans?country=`, `POST /api/video/checkout {plan_key}` → checkout `{id, rail, amount_minor, tax_minor, currency, client}`; sandbox: `POST /api/video/sandbox/pay/{checkout_id}` then poll `GET /api/video/me` until the plan changes; Razorpay: open Razorpay Checkout with `client.key_id/order_id/amount` (rail `razorpay`). Invoices `GET /api/video/me/invoices`, PDF `.../me/invoices/{id}.pdf` (download via axios blob, not a bare link).
- Studio: channel `GET/POST/PATCH /api/video/studio/channel`, avatar/banner multipart; videos CRUD; create video `POST /studio/videos {title, description, visibility, rights_declared:true, ai_generated, tags, filename, size_bytes}` → `{video, upload:{protocol:"put"|"tus", url, method, headers}}`; sandbox: `PUT` the file bytes to `upload.url` with `upload.headers` (XHR for progress); tus (Bunny): `tus-js-client` with `endpoint=upload.url` and the headers as metadata headers; then `POST /studio/videos/{id}/uploaded`. Poll `GET /studio/videos/{id}` for `status` (`uploading→processing→scanning→published|in_review|blocked|failed`) and `ai_status`. Transcript `GET/PUT .../transcript`; captions upload `POST .../captions` (multipart `file`, `language`); suggestions `GET .../suggestions`; clips CRUD + `POST /studio/clips/{id}/render` + `publish`; `download_url` on rendered clips; connected channels `GET /studio/connected`, `GET /studio/connected/youtube/start` → `{url}` (navigate there), `POST .../{id}/sync`, `DELETE`; embeds `POST /studio/embeds {url,title,description,rights_declared}`.
- Trust: `POST /api/video/reports {target_type:"video"|"comment"|"danmaku"|"channel", target_id (public_id/handle/numeric id as string), reason, details}`; reasons: spam, sexual, violence, hate, harassment, self_harm, child_safety, copyright, misinformation, scam, impersonation, other. Public takedown form `POST /api/video/takedowns {kind:"copyright"|"it_rules"|"intimate"|"court_order"|"other", complainant_name, complainant_email, target_url, details, sworn}`. Creator side `GET /api/video/me/moderation`, `POST /api/video/appeals {action_id,text}`.
- Admin (global admin token): `/api/video/admin/stats|queue|reports|actions|appeals|takedowns|ai-usage|videos`.
